Import Engine 1 Target & Performance (all PODS)

One workbook with a "PODS (1)", "PODS (2)" and "PODS (3)" sheet plus a shared "byAccount (BP)" sheet — the monthly Engine 1 ACH file. For every POD found, this sets that POD's Performance snapshot, per-AM Target/YTD Actual/Recurring, and that POD's own Full-Year Target/Achieved/Recurring (as the sum of its AM figures) — it's the authoritative source for those numbers, not just the per-AM table.

Bulk Import from Sales Activity Tracker (.xlsx)

One-time onboarding import: upload a "Sales Activity Tracker" workbook (same layout as Export Tracker sheet on Analytics — one row per activity, with its own POD column) and it creates a new opportunity per row group, distributed into the 8-proof Execution Framework. Each row's own POD column decides which POD it lands in, so one upload can populate multiple PODS at once — this is why only Super Admin can do it. New Account Managers found in the file get an account automatically (temporary password changeme123). This workbook format doesn't carry Strategic Pillar or Stage, so every imported deal defaults to the first configured Pillar and "Prospecting" — review and correct those per opportunity afterward. This only adds new opportunities; it never updates or deletes existing ones, so re-uploading the same file twice will create duplicates.
